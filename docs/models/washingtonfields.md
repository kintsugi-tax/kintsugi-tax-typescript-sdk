# WashingtonFields

State-specific fields for Washington MyDOR portal registration import.

## Example Usage

```typescript
import { WashingtonFields } from "@kintsugi-tax/tax-platform-sdk/models";

let value: WashingtonFields = {
  registrationType: "EXCISE_TAX",
  businessName: "<value>",
  waStateTaxId: "<id>",
};
```
