# NorthDakotaFields

State-specific fields for North Dakota tax portal registration import.

## Example Usage

```typescript
import { NorthDakotaFields } from "@kintsugi-tax/tax-platform-sdk/models";

let value: NorthDakotaFields = {
  registrationType: "SALES_AND_USE_TAX",
  businessName: "<value>",
  ndStateTaxId: "<id>",
  letterId: "<id>",
};
```
