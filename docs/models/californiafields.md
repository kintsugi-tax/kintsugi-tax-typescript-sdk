# CaliforniaFields

State-specific fields for California CDTFA portal registration import.

## Example Usage

```typescript
import { CaliforniaFields } from "@kintsugi-tax/tax-platform-sdk/models";

let value: CaliforniaFields = {
  registrationType: "SALES_TAX",
  businessName: "<value>",
  salesTaxId: "<id>",
};
```
